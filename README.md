# منصة استشارات م. محمد + لوحة تحليلات البيانات وإدارة المواعيد

تطبيق ويب تفاعلي متكامل مبني باستخدام **React 18 + Vite + Tailwind CSS + Apache ECharts** مخصص للمهندس محمد (Solutions Architect Manager).

---

## 🌟 الميزات والمكونات الرئيسية

### 1. الصفحة العامة وتجربة الحجز الذكية
- **التعريف بالخبرات**: عرض مجالات العمل والخدمات (تصميم المعمارية، ترحيل السحابة وFinOps، قيادة الفرق، التحول للمايكروسيرفس، الفحص النافي للجهالة).
- **المنظومة التقنية (Skills & Stack)**: استعراض شامل للأدوات السحابية (AWS, Azure, GCP, K8s, EDA, DDD, TOGAF).
- **محطات المسيرة المهنية (Career Journey)**: خط زمني تفاعلي للمسيرة من هندسة البرمجيات إلى إدارة المعمارية.
- **جدول الحجز الفوري (Booking Experience)**:
  - شريط تقويم تفاعلي يحدد الأيام المتاحة وعدد الفترات الشاغرة بدقة.
  - شبكة الأوقات المتاحة مع فحص فوري لتعارض المواعيد واستثناء الأيام المحظورة.
  - نافذة منبثقة لتأكيد الحجز المباشر مع دعم التأكيد التلقائي.

### 2. لوحة تحليلات البيانات وإدارة الاستشارات (`#/admin`)
- **حماية ببوابة PIN**: رمز الحماية الافتراضي `1234` مع حركة اهتزاز وتنبيهات أمان.
- **بطاقات المؤشرات القيادية (Executive KPI Cards)**:
  - إجمالي الجلسات المسجلة مع مؤشرات النمو الشهري.
  - معدل استغلال المواعيد المتاحة (Slot Utilization Rate) مع أشرطة التقدم.
  - عدد المواعيد النشطة اليوم والقادمة خلال الأسبوع.
  - معدل تأكيد الجلسات ونسبة الطلبات المعلقة.
- **الرسوم البيانية التفاعلية (Apache ECharts)**:
  - **منحنى الإقبال والطلب الزمني (Time-Series Volume Trend)**: مخطط مساحي تدرجي يوضح كثافة الحجوزات.
  - **توزيع الإقبال حسب أيام الأسبوع (Day-of-Week Demand)**: أعمدة بيانية توضح ذروة الطلب.
  - **المجالات الاستشارية الأكثر طلباً (Topic Categorization)**: مخطط دائري مجوف (Donut Chart) لتصنيف اهتمامات العملاء.
  - **تفضيل فترات اليوم (Time-Slot Preferences)**: مقارنة بين فترات الصباح والظهيرة والمساء.
- **جدول البيانات والفلترة التفاعلية (Primary Data Table)**:
  - بحث فوري بالاسم، البريد، أو الموضوع.
  - فلترة بالحالة (مؤكدة، بانتظار التأكيد، ملغاة) والمدى الزمني.
  - ترويسة ثابتة (Sticky Header) وترقيم صفحات بأزرار أيقونات.
  - شريط درجات ملون (Sparkline Indicators) لكل حجز.
- **لوحة التحقيق والتفاصيل المنزلقة (Investigation Side Panel)**:
  - تنزلق عند اختيار أي حجز (`w-1/3` split).
  - تفاصيل العميل، التوقيت، الملاحظات، وإجراءات سريعة (قبول، إلغاء، حذف، إعادة تفعيل).
- **إدارة جدول المواعيد وساعات العمل (Schedule Manager)**:
  - تفعيل/تعطيل أيام الأسبوع وإضافة/حذف فترات العمل اليومية.
  - احتساب تلقائي لعدد الفترات الناتجة بناءً على مدة الجلسة.
- **إدارة الأيام المحظورة (Blackouts Manager)**:
  - إضافة الإجازات والأعياد لتختفي تلقائياً من صفحة الحجز.
- **الإعدادات والنسخ الاحتياطي (Settings & Backup)**:
  - تعديل مدة الجلسة (30/45/60/90 دقيقة)، مدى الحجز المستقبلي، وأقل مهلة إشعار.
  - تغيير رمز المرور (PIN).
  - تصدير واستيراد نسخة احتياطية بصيغة `JSON`.

### 3. التصميم والمظهر (Design System)
- نظام ألوان Zinc المستوحى من Shadcn (Dark & Light Modes).
- زر تبديل المظهر (شمس / قمر) في الترويسة مع حفظ التفضيل في المتصفح.
- خطوط طباعية معتمدة: `DM Sans` و `IBM Plex Sans Arabic` للمحتوى، و `JetBrains Mono` للأرقام والبيانات.
- تصميم متجاوب 100% يعمل بسلاسة على الجوال، الأجهزة اللوحية، والشاشات العريضة.

## 🚀 التشغيل والتطوير المحلي

```bash
# تثبيت الاعتماديات
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build

# معاينة النسخة الإنتاجية المبنية
npm run preview
```

> **ملاحظة**: تم حفظ الملف الأصلي القديم كنسخة احتياطية باسم `index.legacy.html`.
